Comptes Gmail

Gmail n’accepte plus les mots de passe « classiques » pour IMAP/SMTP. Deux options :

  1. Mot de passe d’application (compte Google avec validation en 2 étapes) : Google → Sécurité → Mots de passe des applications → générer → coller dans « Modifier un compte » (IMAP + SMTP) pour imap.gmail.com / smtp.gmail.com.
  2. OAuth (Ortie) : pour Calendula/Cardamum Google, préférez les backends gcal / people avec Ortie plutôt que CalDAV/CardDAV simple.

Le compte mail Gmail se configure comme les autres dans « Modifier un compte » ; seul le type de secret change.
